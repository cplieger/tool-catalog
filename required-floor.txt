# Engine-floor tool names every published catalog MUST resolve, verified by
# `toolcatalog verify` before a release is cut.
#
# This is the floor for a GENERAL catalog: the tools the toolbelt engine itself
# adopts as backends for its own source kinds. Nothing here is a product's
# choice -- every name resolves from mise/aqua registry data alone.
#
#   npm:   -> node   (mise core:node, translated to aqua:nodejs/node)
#   go:    -> go     (mise core:go, translated to aqua:golang/go)
#   pip:   -> uv     (its own aqua registry entry)
#
# cargo: -> rust is deliberately ABSENT. aqua packages `rustup-init`, not a
# toolchain, so a translated entry would land with no `cargo` on PATH; a
# consumer that wants cargo: sources bundles a rust entry of its own.
#
# The DefaultSeed template names (gopls, typescript-language-server,
# typescript, pyright) also left this list: no registry carries them, so they
# are curation and belong to whichever product seeds them. Each consumer
# verifies its own bundled tools at image build with `verify -overlay`.
#
# backend runtimes (auto-adopted dependencies)
go
node
uv
